# M0 code-health audit

Reviewed the full repository at `1baf335` on `main`, including the 13 accepted ADRs, code standards, runtime scaffolding, event contracts and fixtures, infrastructure, and agent workflows.

## Overall assessment

The six initial event types have explicit versions, UUIDv7 event IDs, and contract tests covering valid and invalid fixtures. The collector, event store, event bus, projectors, API and SDKs are scaffolds. Append ordering, replay, conversion deduplication and consent enforcement can be assessed when those components implement them. Resolve the partitioning decision before the first event-store migration and fix the audit validation command before relying on G4.

## Top five findings

- **M0-01 (high) · Install the format plugin in audit validation CI.** The CI validation command exited before reading the instance because ajv-formats could not be resolved. Valid audit reports can fail the audit gate. [.github/workflows/ci.yml:51](../../.github/workflows/ci.yml#L51), [.agents/skills/code-health-audit/schema.json:11](../../.agents/skills/code-health-audit/schema.json#L11)
- **M0-02 (high) · Resolve global event ID uniqueness before implementing partitions.** PostgreSQL 16 requires a unique constraint on a partitioned table to include every partition key column. Uniqueness on event_id alone is unavailable with the specified partition key. Adding occurred_at to the constraint would allow the same ID with a changed timestamp. [docs/adr/0002-postgres-event-store.md:13](../../docs/adr/0002-postgres-event-store.md#L13), [AGENTS.md:49](../../AGENTS.md#L49), [packages/event-store/src/index.ts:1](../../packages/event-store/src/index.ts#L1)
- **M0-03 (medium) · Make audit-to-Linear imports safe to rerun.** If the import stops midway, a workflow rerun creates new issues for findings already imported. A rerun after full success duplicates the entire report. - **M0-04 (medium) · Measure the size:S merge rate per milestone for ADR-0011.** The printed unchanged percentage pools agent PRs across sizes and milestones. Reachability then depends on host and network configuration, leaving the local services unnecessarily exposed.
